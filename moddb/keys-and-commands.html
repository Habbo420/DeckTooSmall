Type commands in the game's chat. They start with a dot.

Keys

KeyWhat it does
F7Smaller UI (steps of 0.5)
F8Bigger UI (steps of 0.5)
F9Open or close the settings window

Change them under Settings > Controls.

General commands

CommandWhat it does
.dtsOpen the settings window (also .dts menu)
.dts helpList the commands
.dts statusShow your current sizes
.dts on / .dts offTurn the mod on or off
.dts size 10Set the size of all menus (4 to 24)
.dts preset compactSmaller than recommended for your screen
.dts preset recommendedThe size suggested for your screen
.dts preset largeLarger than recommended for your screen
.dts resetMake window, text and part sizes follow the main size again

Full screen

CommandWhat it does
.dts fullmap on / offFull-screen world map
.dts fullhandbook on / offFull-screen Handbook
.dts fullsettings on / offFull-screen settings window

Reopen the map or Handbook to see the change.

How to set a size

CommandWhat it does
.dts hotbar 12Set a size, using any name from the list above
.dts hotbar keepKeep it at this size when the main size changes
.dts hotbar followLet it change with the main size again

Sizes use the same numbers as the game's GUI Scale slider (8 is normal). Windows can be 4 to 36. Text and parts are limited compared with the main size: text 60% to 200%, title bar icons and buttons 80% to 150%, item slots 80% to 140%. Close and reopen windows after changing a part.
