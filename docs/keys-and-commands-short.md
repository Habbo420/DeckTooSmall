# DeckTooSmall: short version

| Key or command | What it does |
|---|---|
| `F7` / `F8` | Smaller / bigger |
| `F9` or `.dts` | Settings window |
| `.dts help` | List the commands |
| `.dts on` / `.dts off` | Turn the mod on or off |
| `.dts size 10` | Size of all menus |
| `.dts hotbar 12` | Size of one item |
| `.dts hotbar keep` / `.dts hotbar follow` | Keep that size, or follow the main size |

See the [full list](keys-and-commands.md) for presets, full-screen switches, all item names and size limits.
