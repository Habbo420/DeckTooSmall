# DeckTooSmall: keys and commands

Type commands in the game's chat. They start with a dot.

## Keys

| Key | What it does |
|---|---|
| `F7` | Smaller UI (steps of 0.5) |
| `F8` | Bigger UI (steps of 0.5) |
| `F9` | Open or close the settings window |

Change them under Settings > Controls.

## General commands

| Command | What it does |
|---|---|
| `.dts` | Open the settings window (also .dts menu) |
| `.dts help` | List the commands |
| `.dts status` | Show your current sizes |
| `.dts on / .dts off` | Turn the mod on or off |
| `.dts size 10` | Set the size of all menus (4 to 24) |
| `.dts preset compact` | Smaller than recommended for your screen |
| `.dts preset recommended` | The size suggested for your screen |
| `.dts preset large` | Larger than recommended for your screen |
| `.dts reset` | Make window, text and part sizes follow the main size again |

## Full screen

| Command | What it does |
|---|---|
| `.dts fullmap on / off` | Full-screen world map |
| `.dts fullhandbook on / off` | Full-screen Handbook |
| `.dts fullsettings on / off` | Full-screen settings window |

Reopen the map or Handbook to see the change.

## Sizes you can set

| Name | What it changes |
|---|---|
| `text` | Text |
| `hotbar` | Hotbar and health bars |
| `inventory` | Inventory |
| `character` | Character screen |
| `handbook` | Handbook, when not full screen |
| `chests` | Chests and machines |
| `map` | World map, when not full screen |
| `minimap` | Minimap |
| `other` | Other windows |
| `titlebars` | Title bar icons |
| `buttons` | Text buttons |
| `slots` | Item slots |

## How to set a size

| Command | What it does |
|---|---|
| `.dts hotbar 12` | Set a size, using any name from the list above |
| `.dts hotbar keep` | Keep it at this size when the main size changes |
| `.dts hotbar follow` | Let it change with the main size again |

Sizes use the same numbers as the game's GUI Scale slider (8 is normal). Windows can be 4 to 36. Text and parts are limited compared with the main size: text 60% to 200%, title bar icons and buttons 80% to 150%, item slots 80% to 140%. Close and reopen windows after changing a part.
